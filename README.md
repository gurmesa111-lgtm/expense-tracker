# Expense Tracker

A personal expense tracking project built with Python, HTML, and CSS.

## About

This project aims to help users record expenses and understand their spending. It is currently being developed as a web application.

## Current Features

### Python
- Add and manage expenses
- View recorded expenses
- Calculate total spending
- View spending by category
- Search and filter expenses
- Store expense data locally in JSON format

### Website
- Dashboard layout
- Expense entry form
- Expense table
- Spending by category
- Dark theme with purple accents

The website currently contains a static interface and is not yet connected to the Python program.

## Technologies

- Python
- HTML
- CSS
- JSON
- Git and GitHub

## Project Status

In development. The current focus is improving the website's design and styling. JavaScript and backend integration will be considered as development progresses.
